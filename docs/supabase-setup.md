# راه‌اندازی احراز هویت و پایگاه داده

فاز ۳ از Supabase Auth و PostgreSQL استفاده می‌کند. پروژه در نبود متغیرهای اتصال، تمام مسیرهای داخلی را می‌بندد و فقط صفحه ورود را نمایش می‌دهد.

## متغیرهای محیط اجرا

این مقادیر را در فایل محلی `.env.local` و همچنین تنظیمات محیط مقصد قرار دهید:

```text
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
```

کلید زیر فقط برای اجرای داده‌گذاری اولیه در محیط امن لازم است و نباید در مرورگر یا مخزن قرار گیرد:

```text
SUPABASE_SERVICE_ROLE_KEY=
SEED_DEFAULT_PASSWORD=
```

رمز اولیه باید حداقل ۱۲ نویسه داشته باشد. پس از نخستین ورود، رمز حساب‌ها باید به‌صورت جداگانه تغییر کند.

## ترتیب اجرا

1. یک پروژه Supabase ایجاد کنید.
2. فایل مهاجرت داخل `supabase/migrations` را با Supabase CLI یا SQL Editor اجرا کنید.
3. متغیرهای محیط را وارد کنید.
4. برای ساخت حساب اولیهٔ مدیر عملیات، `npm run db:seed` را اجرا کنید.
5. حساب مدیر عملیات با نام «میلاد» و ایمیل `milad@madar.ir` ساخته می‌شود. پس از ورود، میلاد می‌تواند حساب کارکنان واقعی را از بخش «کارکنان» ایجاد کند.

کلید service role فقط در محیط مدیریت‌شدهٔ سرور نگهداری می‌شود. دسترسی برنامه با publishable key انجام می‌شود و مجوزها در PostgreSQL با RLS اعمال می‌شوند.
