# MinePlus Mobile

اپلیکیشن بومی MinePlus برای Android و iOS با React Native و Expo SDK 57. این پروژه WebView نیست و تمام صفحه‌های عملیاتی را به‌صورت بومی پیاده‌سازی می‌کند.

## بخش‌ها

- ورود امن و نگهداری نشست در SecureStore
- داشبورد، گزارش روزانه شمسی، همکاران، لوکیشن، مخارج و تصویر فاکتور
- تعمیرات، مشتریان، تحویل اقلام و لینک تأیید مشتری
- گردش دستگاه با تعمیرکار و لینک‌های تحویل و بازگشت
- کارهای روزانه مشترک، تاریخچه، بررسی مدیر و فعالیت‌ها
- مدیریت کارمندان و پنل کاربری
- کش محلی SQLite، به‌روزرسانی OTA و Google Play In-App Updates

## اجرای توسعه

```bash
npm install
npm run typecheck
npm run android
```

تنظیمات عمومی Supabase از فایل `.env.local` ریشه پروژه خوانده می‌شود. کلیدهای مدیریتی یا رمز امضای Android داخل مخزن نگهداری نمی‌شوند.

## انتشار

نسخه‌های JS و asset از مسیر EAS Update روی کانال production منتشر می‌شوند. تغییرات native با AAB جدید در Google Play عرضه می‌شوند و خود برنامه جریان In-App Update را اجرا می‌کند.
