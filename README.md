# مدار — سامانه مدیریت عملیات فارم

نسخهٔ فعلی خروجی فاز ۳ است: رابط فارسی RTL فاز قبل اکنون به احراز هویت Supabase، نشست cookie-based، پروفایل‌های نقش‌محور و PostgreSQL با Row Level Security مجهز شده است.

## وضعیت دسترسی

- مدیر سیستم: مدیریت کامل هویت و تنظیمات
- مدیر عملیات: مشاهده کارکنان، بررسی گزارش‌ها و فعالیت‌ها
- کارمند: داشبورد و ثبت گزارش‌های متعلق به خود

مدیر عملیات می‌تواند از بخش «کارکنان» حساب کارمند جدید بسازد. مدیر سیستم علاوه بر کارمند، امکان ساخت مدیر عملیات را نیز دارد.

مسیرهای داخلی بدون نشست معتبر باز نمی‌شوند. در نبود تنظیمات Supabase نیز سامانه به‌صورت امن فقط صفحه ورود را نمایش می‌دهد.

## اجرای محلی

```bash
npm install
npm run dev
```

تنظیم متغیرها، اجرای migration و ساخت حساب‌های اولیه در [راهنمای Supabase](docs/supabase-setup.md) آمده است.

## کنترل کیفیت

```bash
npm run lint
npx tsc --noEmit
npm test
```

معماری و مرزبندی فازها در [سند معماری](docs/phase-1-architecture.md) ثبت شده است. اتصال فرم‌های گزارش و داشبورد به داده‌های واقعی در فازهای بعد انجام می‌شود.
